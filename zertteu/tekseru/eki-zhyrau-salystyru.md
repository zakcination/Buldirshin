# Екі жыраудың куәлігін салғастыру: Бөгенбай батырдың қазасы

Қазақ ауыз әдебиетінде **бір оқиға туралы екі жыраудың бөлек естіртуі** сақталған
жағдай сирек. Бөгенбай батырдың қазасы — дәл сондай жағдай:

- **Үмбетей Тілеуұлы** — «Бөгенбай қазасын Абылай ханға естірту»
- **Бұқар Қалқаманұлы** — «Қазақтың ханы Абылай» / «Батырың өтті — Бөгенбай»

Дереккөзтануда бұл — ең күшті тексеру құралы: екі мәтін бір-біріне тәуелсіз
жасалған, екеуі де бір адресатқа (Абылайға) айтылған.

---

## 1. Сәйкес келетін тұстар (өзара растау)

| Дерек | Үмбетей | Бұқар | Баға |
|---|---|---|---|
| Батырдың руы | «Қанжығалы Бөгенбай» | «Қанжығалы Бөгенбай» | **A** |
| Қабанбайдың руы | «Қаракерей Қабанбай» | «Қаракерей Қабанбай» | **A** |
| Қазыбектің эпитеті | «Қаз дауысты Қазыбек» | «Қаз дауысты Қазыбек» | **A** |
| Хан алдында айтылуы | «Ей, Абылай, Абылай» | «Қазақтың ханы Абылай, / Абылай ханым, бұл қалай?» | **A** |
| Ашылу формуласы | «Абылай ханым, бұл қалай?» | «Абылай ханым, бұл қалай?» | **A** — сөзбе-сөз бірдей |
| Жорық жері | «Ақшәуліге қос тігіп» | «Қол қондырған қос тігіп ... Ақшәулінің өрінен» | **A** |
| Жеңістің нәтижесі | «Арғын менен найманға / Қоныс қылып қалдырдың» | «Қоныс қылған найманға, / Бәрін қуып жерінен» | **A** |
| Тарбағатай өңірі | «Қозы Маңрақ, Қой Маңрақ» (Тарбағатай таулары) | «Асу салған тас бұзып / Тарбағатай белінен» | **A** |
| Ханды жұбату | «Көзіңнің жасын тыя көр» | «Қайғырмаңыз, ханзадам» | **A** |

**Ең маңызды сәйкестік — «Ақшәулі».** Екі жырау да бір топонимді атайды. Сыртқы
тексеру: **Ақшәулі — Тарбағатай жотасының солтүстік-батысындағы нақты тау
(1618 м, Абай облысы, Үржар ауданы)**. Демек:

1. Топоним ойдан шығарылмаған;
2. Бұқардың «Тарбағатай белінен» деген жолы Ақшәулінің нақты орналасуымен дәлме-дәл
   түседі — яғни екі жыраудың географиясы бір-бірімен де, картамен де үйлеседі;
3. Үмбетейдегі «Ақшәуліге қос тігіп» пен Бұқардағы «қос тігіп ... Ақшәулінің өрінен»
   — бірдей іс-әрекет (қос тігу = тұрақ салу) бір жерде айтылған.

Бұл — жыр географиясының **картаға түсетінінің** дәлелі. Деңгей: **A**.

## 2. Айырмашылықтар (қайшылық емес, толықтыру)

| Мәселе | Үмбетей | Бұқар |
|---|---|---|
| Қаза жағдайы | Егжей-тегжейлі: жасы, өлер сәті, соңғы сәлемі | Мүлде айтылмайды |
| Хабарды жеткізуші | «Батырды қолдан өткіздім, / Сәлемін міне жеткіздім» | «Қарияң келіп жылап тұр» |
| Абылай өмірбаяны | Толық хронология (жастығы, тұтқыны, жорықтары) | Жоқ (бұл бөлек жырларда) |
| Орта жүздің тірегі | **Бес**: Жәнібек, Қазыбек, Құттыбай, Қабанбай, Бөгенбай | **Төрт**: Қабанбай, Бөгенбай, Қазыбек, Жәнібек |
| Қоныс кімге қалды | **Арғын мен найманға** | Тек **найманға** |
| Жәнібектің тегі | «**Керейде** батыр Жәнібек» | «**Шақшақұлы** Жәнібек» |

### 2.1. Кім естіртті? — шешілмеген мәселе

Екі жырау да қаза хабарын өзі жеткізгендей сөйлейді. Ықтимал түсіндірмелер:

1. **Екеуі де қатысқан.** Естірту — көп адам қатысатын рәсім; әркім өз сөзін
   айтқан. Мәтіндер бір-біріне қайшы келмейді: Үмбетей «мен қасында болдым» дейді,
   Бұқар «қария келіп тұр» дейді — бұл үшінші жақ, өзін сырттай сипаттауы мүмкін.
2. **Мәтіндердің бірі кейін соған теліну арқылы қалыптасқан.**
3. **Екі бөлек оқиға** (мысалы, бірі — қаза хабары, екіншісі — асында айтылған сөз).

Қазіргі деректермен шешу мүмкін емес. Деңгей: **D**. Ең ықтимал — 1-нұсқа.

### 2.2. «Төрт тірек» пе, «бес тірек» пе?

Бұқарда тұрақты формула: «Ормандай көп Орта жүз, / Сондан шыққан **төрт тірек**» —
төртеуі де **Орта жүз** өкілдері (Найман-Қаракерей, Арғын-Қанжығалы, Арғын-Қаракесек,
Арғын-Шақшақ).

Үмбетейде **бесеу**, оның ішінде «Қу дауысты Құттыбай» бар. Сыртқы дерек бойынша
Құттыбай би — **найман, Қаракерей-Сыбан**, яғни ол да Орта жүз. Демек Үмбетейдің
тізімі Бұқардың формуласын **бұзбайды, кеңейтеді**.

Тұжырым: «төрт тірек» — Бұқар қалыптастырған тұрақты формула, Үмбетей одан еркін.
Екеуі қайшы емес.

### 2.3. «Керейде Жәнібек» мәселесі — Бұқар арқылы шешілуге жақын

Бұқарда **екі жерде** (Бөгенбай естіртуінде және Қалдан шайқасының тізімінде)
дәйекті түрде «**Шақшақұлы Жәнібек**» тұр. Оның үстіне Бұқардың өз мәтінінің
А нұсқасында «**Шашақ ұлы** Жәнібек» деп бұрмаланып кеткені көрініп тұр.

Демек:
- Тарихнамадағы Шақшақ Жәнібек Қошқарұлы (1693–1752, арғын) — расталады;
- «Шақшақұлы → Шашақ ұлы» ауысуы **бір мәтіннің ішінде тіркелген**;
- Үмбетейдегі «Керейде батыр Жәнібек» — сол типтегі ауысу болуы ықтимал.

Тізілімдегі T-6 деңгейі **D → B-ге** түзетіледі: Жәнібектің Шақшақ (арғын) екені
Бұқардың қос куәлігімен бекітіледі, ал «Керейде» нұсқасы мәтін тарауындағы
бұрмалау деп бағаланады (толық дәлелдеу үшін Үмбетей мәтінінің қолжазба нұсқалары
қажет).

### 2.4. «Арғын мен найман» / «тек найман»

Үмбетейдің өзі — арғын-қанжығалы, ол «арғын менен найманға» дейді. Бұқар да
арғын (Сүйіндік-Қаржас), бірақ «найманға» дейді. Яғни айырманы «жырау өз руын
қосып жіберген» деп түсіндіру Бұқарға келмейді.

Ықтимал шешім: Ақшәулі–Тарбағатай өңірі **найман қонысына** айналған (бұл бүгінгі
этнографиялық жағдаймен де сай), ал Үмбетей жалпы шығысқа жылжуды (Баянауыл,
Шыңғыстау — арғын жері) қоса айтқан. Екі дерек бір-бірін толықтырады.

## 3. Бөгенбайдың сыналуы — үшінші, күтпеген қабат

Бұқардың «Абылай ханның асында» жырында:

```
Уа, сен қанжығалы Бөгенбай,
Тоқымы кеппес ұры едің.
Түн жастанып жүр едің,
Қабанбайдан бұрын найзаңды
Қашан жауға тіредің?
```

Салыстырыңыз — Үмбетейдің «Бәкеге» жырында:

```
Тоқымы кеппей топтанып,
Ел тонауға аттанып,
...
Жаудай шапқан не сұмдық!
```

**Екі жырау да бір идиоманы («тоқымы кеппес/кеппей») барымта мен түнгі шабуылды
сипаттауға қолданады.** Бұл:

1. Идиоманың сол дәуірде тұрақты болғанын көрсетеді;
2. Батырлардың барымтаға араласқанын **екі тәуелсіз көзбен** бекітеді;
3. Ең бастысы: жыраулар батырды тек мадақтамаған — бетіне басып сынаған.

Бұл Бөгенбайдың портретін өзгертпейді, бірақ **толықтырады**: ол — ел қорғаушы да,
барымташы да болған дәуірдің адамы. Ғаламтордағы бір өлшемді «мінсіз батыр» бейнесі
бастапқы дереккөзде расталмайды.

Деңгей: **A** (екі тәуелсіз жырау).

## 4. Жиынтық қорытынды

| Не тексерілді | Нәтиже |
|---|---|
| Ру-тегі атаулары | Екі жырауда бірдей — **A** |
| Жорық географиясы (Ақшәулі, Тарбағатай) | Екі жырауда бірдей әрі нақты географиямен расталды — **A** |
| Жеңістің нәтижесі (қоныс) | Екі жырауда бірдей — **A** |
| Жәнібектің руы | Бұқар екі рет «Шақшақұлы» дейді — **B→A жақындады** |
| Батырдың сыналуы | Екі жырауда бірдей идиома — **A** |
| Қаза жағдайы | Тек Үмбетейде — **B**, бірақ куәгерлік сипатта |
| Кім естіртті | Шешілмеген — **D** |
