# Толық қаһармандар тізілімі — шеңбері мен күйі

> Құрылған күні: 2026-11-03. Файлы: `data/qaharmandar.yaml`.

## 0. Неге бұл файл керек

Жобада екі бөлек нәрсе болды, бірақ олар бір-бірімен жалғанбады:

| | Не бар еді | Мәселесі |
|---|---|---|
| **Проза қабаты** | `02-epos-korpusy.md`, `03-19-gasyr.md`, `04-shetel.md` — жүзден асатын есім, шифрымен, деңгейімен | Адам оқиды, машина оқымайды. «Барлық батырды көрсет» деген сұрауға жауап жоқ |
| **Тізілім қабаты** | `data/batyrlar.yaml` — **9** жазба | Прозада жүз есім бар, тізілімде тоғыз. Айырма — 100-ден астам |

`qaharmandar.yaml` сол айырманы жабады: прозада **әлдеқашан тіркелген** әр
есім машинаға оқылатын жазбаға айналды. **Жаңа іздеу жүргізілмеді** — әр
жазбаның `source_doc` өрісі оның қай құжаттан алынғанын көрсетеді.

## 1. Екі қабат ережесі — шатастырмау керек

| | `qaharmandar.yaml` | `batyrlar.yaml` |
|---|---|---|
| Не дейді | «бұл есім зерттеуде тіркелген, дереккөзі мынау» | «бұл тұлға зерттелген: оқиғалары, сипаттамалары, дереккөздері талданған» |
| Жазба саны | **112** | **9** |
| `status` | `тізімде` | `зерттелген` |
| Жалғауышы | `passport` өрісі → `batyrlar.yaml` id-і | — |

**Тізімде болу — зерттелген деген сөз емес.** Валидатор (`tizilim_check.py`)
осы екеуінің үйлесімін тексереді: `passport` бар болса `status` міндетті түрде
`зерттелген`, жоқ болса `тізімде`.

## 3. Ең мықты қабат — Қырық батыр циклы

48 жазбаның 27-сі **A** деңгейінде, себебі `02-epos-korpusy.md` §3.4 кестесі
әр жыр үшін бесеуін бірге береді: **айтушы** (Мұрын жырау), **жазып алған
адам**, **жылы**, **том:бет**, **қолжазба шифры**.

Бұл — ғаламтордағы кез келген тізімнен артық. Салыстыру үшін: `el.kz` пен
Уикипедия тізімдері есімдерді ғана береді, шифры да, жазып алған адамы да жоқ.
Сондықтан циклдің 40 жазбасы академиялық томнан, қалған 8-і ғаламтор
тізімдерінен алынды және **C** деңгейінде тұр:

Матай, Жанбай, Ақжонас, Бозтуған, Темір хан, Әділ, Шырман, Баба түкті Шашты
Әзиз — бұл сегізінде 50–51 томдарда **жеке мәтін жоқ**. Валидатор оларды
`corpus` өрісі жоқ деп белгілейді — бұл қате емес, **белгі**: бұл есімдер
академиялық корпуспен расталмаған.

### Цикл санының дауы — D

| Дереккөз | Саны |
|---|---|
| kk.wikipedia (мәтін ішінде) | 41 батыр, 36 жыр |
| kk.wikipedia (энциклопедиялық анықтама) | 40 батырдың ерлігі |
| `el.kz` | 40 нөмірленген жазба, ішінде 42 бөлек есім |
| `inform.kz` | алғашында 36, 1947 ж. тағы 4 қосылған |
| «Бабалар сөзі» 50, 51-томдар | 17 + 20 = **37 мәтін** |

Бесеуі де әртүрлі. Сондықтан **нақты сан — D**. Жобада қолданылатын тұжырым:
«академиялық басылымда 37 мәтін бар», ал «қырық батыр» — циклдің **атауы**,
санақ емес.

## 4. Әлі жабылмағаны

**1. XX ғасыр қабаты — шеңберден тыс, шешім керек.** Тізімде `XX` tier-і
валидаторда бар, бірақ бірде-бір жазба жоқ. Бұған кіретіндер: Алаш
қайраткерлері, Ұлы Отан соғысының батырлары (Бауыржан Момышұлы, Әлия, Мәншүк,
Талғат Бигельдинов, Рақымжан Қошқарбаев), «Халық Қаһарманы» атағының
иегерлері. Бұл — **бөлек дереккөз түрі**: жыр емес, жарлық пен архив. Жобаның
балалар контенті осыны қамтиды ма — шешілмеген.

**2. 56–61 томдар толық сұрыпталмады.** `тарихи-жыр` қабатының 17 жазбасы
`02-epos-korpusy.md` §7.4-тегі кестеден алынды, ал ол кестеде томдардың **бет
деңгейіндегі** тізімі жоқ. Яғни 56–61 томдарда аталған әр тұлғаның жыр саны
мен шифры әлі белгісіз — сондықтан бүкіл қабат **B** деңгейінде тұр, бірде-бір
A жоқ.

**3. Есімдес Жәнібектер ажыратылмады.** Кемінде **төрт** Жәнібек бар:
56-томдағы «Батыр Жәнібек», 59-томдағы «Жәнібек батыр», 61-томдағы
«Шақшақұлы Ер Жәнібек», 27-томдағы «Керей Ер Жәнібек Бердәулетұлы».
Екеуінің паспорты бар (`shaqshaq-zhanibek`, `kerey-er-zhanibek`), қалғаны
қайсысы екені анықталмады.

**4. Қазтуған — екі тұлға ма, бір тұлға ма.** 51-томдағы «Қарғабойлы,
Қазтуған» мәтініндегі Қазтуған мен Қазтуған жырау (XV ғ., `zhyraular.yaml`)
бір адам ба — тексерілмеді. `el.kz` тізіміндегі «Бозтуған» да осымен
шатасуы ықтимал.

**5. Қос рөлді тұлғалар толық белгіленбеді.** `00-shema.md` §2а бойынша
батыр әрі жырау болғандар екі жазба алуы керек. Тізімде белгіленгені:
Асанқайғы, Махамбет, Арғынбек Апашпайұлы, Ақыт қажы. Толық тексеріс
жүргізілмеді.

## 5. Толтыру реті

1. **XVIII ғасырды бітіру** — жобаның өзегі. 6 жазбаның бесеуінде паспорт бар;
   қалғаны мен 58-томдағы Бөгенбай/Қабанбай мәтіндерінің шифрлары.
2. **Қырық батыр циклының C деңгейіндегі 8 есімін шешу** — олар шынымен
   циклде бар ма, жоқ па. Бұл ӘӨИ мен ОҒК қорына сұраныс арқылы шешіледі
   (`02-epos-korpusy.md` §7.1-де шифрлар бар).
3. **56–61 томдарды бет деңгейінде сұрыптау** — `тарихи-жыр` қабатын B-дан
   A-ға көтеретін жалғыз жол.
4. **Есімдес тұлғаларды ажырату** — Жәнібектер, Олжабайлар, Қазтуғандар.
5. **XX ғасыр туралы шешім** — шеңберге кіреді ме.

## 6. Қалай сұрау салуға болады

```bash
python3 -I pipeline/normalize/tizilim_check.py        # тұтастық тексерісі
```

```python
import yaml
q = yaml.safe_load(open('zertteu/tizilim/data/qaharmandar.yaml'))['qaharmandar']

# A деңгейіндегі барлық қаһарман
[x['name'] for x in q if x['level'] == 'A']

# паспорты жоқ, бірақ A деңгейіндегілер — зерттеуге кезекте тұрғандар
[x['name'] for x in q if x['level'] == 'A' and not x['passport']]

# Мұрын жырау жырлағандар
[x['name'] for x in q if 'Мұрын' in (x.get('performer') or '')]
```

Үшінші сұраудың жауабы — **40 есім**: бір айтушыдан жазылған қабат жобадағы
ең ірі біртұтас дереккөз. Мұрын жыраудың өз паспорты `zhyraular.yaml`-да
тұруы керек — тексерілмеді.
