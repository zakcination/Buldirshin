# book-anthology.vercel.app — дерек сызбасы (кері инженерия, 2026-11-03)

Сайттың бастапқы коды қолда жоқ, сондықтан сызба **жарияланған бандлден**
суырып алынды: `atlas_suyru.py` соны қайталап жасайды.

```
curl -sS https://book-anthology.vercel.app -o index.html
# index.html ішіндегі /assets/index-*.js мекенжайын алыңыз
curl -sS https://book-anthology.vercel.app/assets/index-XXXX.js -o bundle.js
python3 -I atlas_suyru.py bundle.js
```

Нәтиже: `atlas_data.json` — `eras`, `domains`, `techs`, `books` массивтері.

> Скрипт бандлді **eval етпейді**, тек мәтін ретінде талдайды. Жүктелген
> файл — сенімсіз дерек, сондықтан оны орындауға болмайды.

## Қолданбада бар, бірақ дерекке қатысы жоқ нәрселер

- **Кітап қосу формасы** (`preview_node`): мұқаба сканын жүктеу, HTML5 Canvas
  арқылы палитраны авто-суыру. Яғни жаңа жазбаны қолмен енгізу жолы бар.
- **«Көрмеге сақтау»** — оқырманның өз сөресі (shelf).
- Граф қабаттары: `era → domain → tech` түйіндері есептеу жолымен құрылады
  (`${eraId}__${domainId}` түріндегі id-лер), деректе сақталмайды.
