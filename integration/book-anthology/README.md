# book-anthology.vercel.app — интеграция қабаты

> Күйі: **дайындық бітті, біріктіру кодқа қолжетімділікті күтеді** (2026-11-03).

`book-anthology.vercel.app` — «Қазақ кітаптарының таксономиясы — Ұлттық
библиографиялық атлас»: қазақ кітап басылымының тарихын интерактивті білім
графы ретінде көрсететін Vite + React қолданбасы.

Бұл бума — Buldirshin зерттеуін сол атласқа қосуға дайындалған қабат.

| Файл | Не үшін |
|---|---|
| `shema.md` | Атластың дерек сызбасы — өрістер, enum-дар, шарттар |
| `atlas_suyru.py` | Жарияланған бандлден дерек массивтерін суырып алатын скрипт |
| `kitaptar.buldirshin.json` | Атлас сызбасындағы **5 жаңа жазба** (`b715`–`b719`) |

### Осы жол бойында шешілген үш сұрақ

**1. «Бес ғасыр жырлайды» — екі бөлек басылым.** Каталог көрсетті: 1985 жылғы
**үш томдық** (құраст. М. Байділдаев, М. Мағауин; ҚазССР ҒА М. О. Әуезов
атындағы Әдебиет және өнер институты; 3-том 352 б.) және 1989 жылғы
**екі томдық** (таралымы 100 000, 1-том 384 б., ISBN 5-605-00358-5).
Кітапханаға жазылған хаттағы «басылым нұсқалары әртүрлі» деген негіз —
енді гипотеза емес, **расталған факт**. Хаттың 2-сұранысындағы бірінші жол
осымен ішінара жабылды: библиографиялық анықтама қолда, қалғаны — мәтінге
қолжетімділік.

**2. Затаевич жинағының қайсысы KazNEB-те бар.** `kontent/muzyka-klassika.md`
§6.3-тегі 16-тармақ «1925 және 1931 жж. жинақтарының сканы табылмады» деп
тұрған. Нақтыланды: каталогта **1963 жылғы 2-басылым** бар (Мәскеу: Музгиз,
606 б., жауапты ред. А. Қ. Жұбанов). 1925 жылғы Орынбор бірінші басылымы мен
1931 жылғы «500 күй мен ән» әлі **табылмады** — тармақ ашық қалады, бірақ
енді нақтырақ: іздеу 1963 жылғы басылымнан бастауға болады.

**3. «Қаракерей Қабанбай (Жазушы, 1991)» — каталогта табылмады.** Хатта
З. Сәнікұлы мен Б. Садықанұлының 1991 жылғы басылымы сұралған. KazNEB-те
осы атаумен тұрған жазба — **басқа кітап**: Ш. Күмісбайұлы, Алматы: Аруна,
2007, 92 б., «Шығыстың ұлылары» сериясы, Қабдеш Жұмаділовтың «Дарабоз»
романы бойынша жазылған. ӘДІСТЕМЕ §6 бойынша каталогтың үнсіздігі «жоқ»
дегенді білдірмейді — 1991 жылғы басылым бар болуы мүмкін, бірақ оны
кітапхана арнасынан сұрау керек. Хаттың тізімі өзгермейді.

## Сызбаға қосылатын төрт өріс (`bld*`)

Атластың өз сызбасы өзгермейді — төртеуі де **қосымша, міндетті емес**.
Қолданба оларды оқымаса да, жазбалар бұзылмайды.

| Өріс | Мәні |
|---|---|
| `bldEvidence` | A–E дәлел деңгейі (`ADISTEME.md`) |
| `bldSourceTier` | I–V дереккөз иерархиясы. I — заманхат, IV — академиялық, V — ғаламтор/рецепция |
| `bldDocuments` | Осы басылым дәйектейтін тұлғалардың тізілім id-лері (`Z-*`, `N-*`, `B-*`) |
| `bldNote` | Каталогтан алынған нақтылау мен ашық қалған сұрақ |

Бұл — атластың **библиографиялық** қабатына Buldirshin-нің
**дереккөзтанулық** қабатын жалғайтын жік. Каталог «бұл кітап бар» дейді;
`bld*` өрістері «бұл кітаптағы дерек қандай деңгейде және кім туралы» дейді.
Екеуі бірігіп, атластағы кітапты тұлғаға байланыстырады.

## Біріктіру тәртібі

1. Атластың репозиторийінде кітап массиві жататын файлды табу (бандлде ол
   `zi=[{id:"b01",…}]` түрінде, яғни бір литерал массив — `src/data/` ішінде
   болуы ықтимал).
2. `kitaptar.buldirshin.json` ішіндегі 5 жазбаны массив соңына қосу.
3. `coverImageUrl` — бесеуінде де `null`. Қолданба мұны қолдайды: сканы
   жоқ жазбаға үлгілік мұқаба сызып, «түпнұсқа скан емес» деп жазады.
   Нақты мұқаба керек болса, KazNEB-тің `bookView` бетінен алынады.
4. `pnpm build` (не `npm run build`) — enum мәндері сызбаға сәйкес, типтік
   қате күтілмейді.

## Әзірге жабық тұрған нәрсе

Атластың **бастапқы коды бұл сессияға қолжетімсіз**. `book-anthology` деген
репозиторий GitHub тізімінде жоқ; `buldirshin-site` — бір беттік статикалық
`index.html` (GitHub Pages), `buldirshin-studio` — контент репозиторийі,
`site` деген submodule-і `buldirshin-site`-қа кетеді. Vercel жобасы жергілікті
бумадан не басқа аккаунттан шығарылған болуы мүмкін.

Сондықтан PR ашу мүмкін емес. Код қолжетімді болған сәтте біріктіру жоғарыдағы
төрт қадаммен бітеді.
