## Неге хат жазу — құбырдың бірінші қадамы

`pipeline/README.md` бетінде жазылғандай, парсер жазар алдында ресми жол
сыналуы керек. Себебі ол:

| Өлшем | Ресми хат | Парсер |
|---|---|---|
| Уақыт | бірнеше күн | апталар |
| Құқықтық тәуекел | жоқ | пайдалану шартын бұзу қаупі |
| Скан сапасы | түпнұсқа | сайттағысы қандай болса, сондай |
| Жалғасы | байланыс орнайды | жоқ |

## Хатқа не міндетті түрде кіруі керек

1. **Зерттеудің нақты мәні** — жалпы сөз емес, нәтиже мысалдары. Кітапхана
   қызметкері жобаның шын екенін көруі керек.
2. **Нақты басылымдар тізімі** — «жырау мұрасы» емес, атауы мен жылы көрсетілген
   тізім.
3. **Деректі қалай пайдаланатыныңыз** — әсіресе авторлық құқық бойынша. Біздің
   жағдайда: толық мәтін жарияланбайды, тек дәйексөз бен бет сілтемесі.
4. **Икемділік** — оқу залы, уақытша қолжетімділік, жеке беттер сканы: қайсысы
   болса да жарайтынын айту.

## Ескерту: адресат таңдау

Барлық материал бір жерде жатпайды:

| Не керек | Қайда іздеу |
|---|---|
| Баспа кітаптар (1989, 1991, т.б.) | Ұлттық академиялық кітапхана, kazneb.kz |
| **Қолжазбалар** (Мәшһүр Жүсіп) | **М.О.Әуезов атындағы Әдебиет және өнер институты** |
| Күй жазбалары | Ұлттық фонотека, Қазақ радиосының қоры |
| Архив құжаттары | ҚР Орталық мемлекеттік архиві |

Әрқайсысына бөлек хат керек.
