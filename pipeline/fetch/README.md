# fetch — алу сатысы (әлі жазылмаған)

Мұнда код жоқ. Себебі: сайттың нақты құрылымын көрмей селектор жазу — сынақтан
өтпеген, жалған жұмыс. Ол репозиторийдің «дәлелденбегенді дәлел деп берме» деген
қағидасына қайшы.

## Жазар алдында орындалатын тәртіп

1. `robots.txt` оқу, пайдалану шарттарын оқу.
2. Кітапханаға ресми сұраныс жіберу (`../sources.yaml` → `access_plan`).
3. Браузердің Network қойындысынан **ішкі API** бар-жоғын қарау. Көбіне JSON
   қайтаратын эндпоинт табылады — сонда Selenium керек емес.
4. Бір ғана құжатпен қолмен толық цикл өткізу.
5. Тек содан кейін код жазу.

## Техникалық шешім реті

| Жағдай | Құрал |
|---|---|
| Тікелей PDF сілтемесі | `requests` |
| Статикалық HTML | `requests` + `BeautifulSoup` |
| JS шақыратын ішкі API | `requests` (сол API-ға тікелей) |
| Тек JS-пен көрінетін көрсеткіш | `playwright` (Selenium емес) |

## Міндетті шектеулер

- Сұраныс аралығы ≥ 1–2 сек, қатарлас жүктеу жоқ.
- `User-Agent` ішінде жоба аты мен байланыс поштасы.
- Қайта жүктемеу: `checksum` бойынша тексеру.
- Қате болса — тоқтау, қайталап соқпау.
