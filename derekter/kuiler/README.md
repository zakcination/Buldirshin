# Күй дереккөздері — жиналу үстінде

Зерттеу жоспарында күй мен күй аңызы **екінші деңгейлі бастапқы дереккөз** ретінде
қаралады (қараңыз `ADISTEME.md`).

## Қазіргі күй-жайы: бос

2026-08-19 күні жүргізілген іздеу барысында **Бөгенбай, Қабанбай немесе Абылай
тақырыбындағы нақты күйдің атауы, орындаушысы және аңызы көрсетілген сенімді
дереккөз табылмады**. Іздеу нәтижелері батырлар туралы жыр-дастандарға қайта
бағыттады. Бұл — олқылық, жасырылмайды.

## Жиналуы тиіс материал

| Не жиналады | Қайдан |
|---|---|
| Күй атауы + аңызы (мәтіні) | А.Жұбанов «Ғасырлар пернесі», «Қазақтың 1000 күйі» жинағы |
| Күйдің шығу тарихы туралы дәстүрлі әңгіме | Күйші-орындаушылар мұрағаты, ҚР Ұлттық кітапханасы |
| Жоңғар соғысы дәуірінің күйлері | Қорқыт ата, Байжігіт, Тәттімбет мектептері бойынша зерттеулер |
| Дыбыс жазба сілтемесі | Ұлттық фонд, «Қазақ радиосы» архиві |

## Талап

Күй қосылғанда әр файлда болуы тиіс: күй атауы, күйші, мектебі, аңыз мәтіні,
аңыздың алғаш қай жинақта жазылғаны, дыбыс жазбасына сілтеме, және аңыздағы
тексерілетін тұжырымдар тізімі (жыр мәтіндеріндегідей).
