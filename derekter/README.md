# Бастапқы дереккөздер

Бұл бумадағы мәтіндер **өзгеріссіз** сақталады. Емле қателері, диалект нұсқалары,
күмәнді жолдар түзетілмейді — әр мәтіннің соңындағы «Мәтіндік ескертпелер» бөлімінде
тіркеледі. Талдау мен пікір бұл бумаға жазылмайды, ол `zertteu/` бумасында.

## Мазмұны

- `umbetey-tileuuly/` — Үмбетей жырау Тілеуұлының жырлары (7 мәтін)
- `buqar-zhyrau/` — Бұқар жырау Қалқаманұлының жырлары (42 мәтін, 6 топтама)
- `kuiler/` — күй дереккөздері (жиналу үстінде)

## Ескерту: бір автордың мұрасы біртекті емес

Бұқар корпусы көрсеткендей, бір жырауға телінген мәтіндердің дәлел салмағы бірдей
болмайды. Мәтіндер қабаттарға бөлінеді (заманхат өзек / дидактика / кейінгі
қосындылар), әр қабат бөлек бағаланады. Қараңыз: `zertteu/zhyraular/buqar-zhyrau.md`.

## Мәтін паспортының өрістері

| Өріс | Мағынасы |
|---|---|
| Автор | Жырау/ақын аты |
| Жанр | толғау, естірту, арнау, сын, жоқтау |
| Кімге арналған | Адресат |
| Шамамен айтылған жылы | Мәтін ішіндегі оқиғаға қарап анықталады |
| Мәтін көзі | Осы нұсқа қайдан алынды |
| Тексеру күйі | Академиялық басылыммен салғастырылды ма |
