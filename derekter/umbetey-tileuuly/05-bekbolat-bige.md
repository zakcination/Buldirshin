# Бекболат биге

| Өріс | Мәлімет |
|---|---|
| Автор | Үмбетей жырау Тілеуұлы |
| Жанр | Толғау-арнау (нақыл) |
| Кімге арналған | Бекболат би |
| Шамамен айтылған жылы | Белгісіз |
| Мәтін көзі | Тапсырмамен ұсынылған нұсқа |
| Тексеру күйі | Академиялық басылыммен салғастырылмаған |

## Мәтін

```
Мен пайғамбардан бастасам,
Әңгімеге кетермін.
Едігеден бастасам,
Ертегіге кетермін.
Келтесінен қайырсам,
Сөз түбіне жетермін.
Енді сізге не дермін:
Бай болмаған бай болса,
Жайламаған сай қоймас.
Би болмаған би болса,
айтылмаған сөз қоймас.
Хан болмаған хан болса,
Қанамаған ел қоймас.
Баласын мақтар бас жаман,
Қатынын мақтар қас жаман.
Алыстағы дұшпаннан,
Андып жүрген дос жаман,
Бір түйе бітпей түйе болмас,
Өз малын кізнеген,
Кісі малын іздеген
Түбінде өз малына ие болмас!
```

## Мәтіндік ескертпелер

- «айтылмаған» жолы кіші әріппен басталған (басылым қатесі).
- «кізнеген» — «күзеткен/қызғанған» мағынасындағы сирек тұлға; нұсқа айырмасы болуы мүмкін.

## Дереккөздік мәні

1. **«Едігеден бастасам, ертегіге кетермін»** — Үмбетейдің **дереккөз иерархиясын
   өзі саралағанының** дәлелі: Едіге туралы айтылатын нәрсені ол «ертегі» деп,
   өз заманының дерегінен ажыратып тұр. Жыраудың өзі шындық пен аңызды бөлген.
   Бұл — осы репозиторийдің әдістемесіне тікелей негіз.
2. **«Хан болмаған хан болса, қанамаған ел қоймас»** — билік сынының формуласы;
   XVIII ғ. саяси ойының дерегі.
