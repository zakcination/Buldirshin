# Бөгенбай өліміне

| Өріс | Мәлімет |
|---|---|
| Автор | Үмбетей жырау Тілеуұлы |
| Жанр | Жоқтау-мадақ (арнау) |
| Кімге арналған | Қанжығалы Бөгенбай батыр |
| Шамамен жылы | 1775 ж. шамасы (батыр қайтыс болғаннан кейін) |
| Мәтін көзі | Тапсырмамен ұсынылған нұсқа |
| Тексеру күйі | Академиялық басылыммен салғастырылмаған |

> **Дереккөздік маңызы:** мәтінде **әке аты, жорық бағыты және жеңістің саяси
> нәтижесі** аталады. Бұл — Бөгенбай батыр туралы ең тығыз дерек шоғыры.

## Мәтін

```
Уа, Алатаудай Ақшадан
Асып тудың, Бөгенбай!
Болмашыдай анадан
Болат тудың, Бөгенбай!
Қалақайлап дулатқан,
Қалдамандап шулатқан
Қалмақты алдың, Бөгенбай!
Құбыла көшкен байтақтың
Ордасындай Бөгенбай!
Темір жұмсап, оқ атқан
Қорғасындай Бөгенбай!
Қолтығы ала бұғының
Пәйкесіндей Бөгенбай!
Жалаңқия жерлерден
Жазбай түсіп түлкі алған
Білегі жуанбүркіттің
Тегеурініндей Бөгенбай!
Баянаула, Қызылтау,
Абыралы, Шыңғыстау,
Қозы Маңрақ, Қой Маңрақ,
Арасы толған көп қалмақ;
Қалмақты қуып қашырдың,
Қара Ертістен өткізіп,
Алтай тауға асырдың!
Ақшәуліге қос тігіп,
Ауыр қол жидырып алдырдың;
Қалмаққа ойран салдырдың!
Қабанбай мен Бөгенбай,
Арғын менен найманға
Қоныс қылып қалдырдың!
```

## Мәтіндік ескертпелер

- «Маңрақ» — тарихи-географиялық әдебиетте «Маңырақ» (Тарбағатайдағы Қозы Маңырақ,
  Қой Маңырақ таулары).
- «жуанбүркіттің» — «жуан бүркіттің» болып бөлек жазылуы тиіс сияқты.
- «Ақшәуліге» — жер-су аты; анықтауды қажет етеді (Бөгенбайдың әкесі Ақшаның
  атымен байланысты ма деген болжам тексерілмеген).
- «Қалдамандап» — «Қалдан!» деп ұрандаған мағынасында болуы ықтимал.

## Мәтіннен бөлініп алынған тексерілетін тұжырымдар

| № | Жыр жолы | Тұжырым |
|---|---|---|
| 15 | «Алатаудай Ақшадан / Асып тудың» | Бөгенбайдың әкесі — Ақша |
| 16 | «Баянаула, Қызылтау, / Абыралы, Шыңғыстау, / Қозы Маңрақ, Қой Маңрақ» | Жорық аймағы: Сарыарқаның шығысы → Тарбағатай |
| 17 | «Қалмақты қуып қашырдың, / Қара Ертістен өткізіп, / Алтай тауға асырдың» | Жоңғарды Қара Ертістен асырып қуған |
| 18 | «Арғын менен найманға / Қоныс қылып қалдырдың» | Жеңістің нәтижесі — арғын мен найманның шығысқа қоныстануы |

Осы тұжырымдардың тексерілуі: `zertteu/tekseru/tekseru-registri.md`.

## Жанрлық ескертпе

Тақырыбы «Бөгенбай өліміне» болғанымен, мәтіннің өзінде қаза туралы бір жол да жоқ —
түгелдей тірі кезіндегі ерлікті тізу. Кейбір басылымдарда бұл мәтін **мадақ жыры**
ретінде де беріледі. Атаудың мәтінге қатысы тексеруді қажет етеді (қараңыз:
`zertteu/tekseru/tekseru-registri.md`, T-19).
