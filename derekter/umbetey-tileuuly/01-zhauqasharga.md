# Жауқашарға

| Өріс | Мәлімет |
|---|---|
| Автор | Үмбетей жырау Тілеуұлы |
| Жанр | Сын-арнау |
| Кімге арналған | Жауқашар |
| Шамамен айтылған жылы | Белгісіз |
| Мәтін көзі | Тапсырмамен ұсынылған нұсқа |
| Тексеру күйі | Академиялық басылыммен салғастырылмаған |

## Мәтін

```
Бұрала біткен емендей,
Қисық туған адамсың.
Бұл мінез, бұл қылықпе
Қайдан абырой табарсың?!

Ындыны жаман жетеуің
Қашты әне жалт беріп,
Қалған мына екекуін
Қолыңа ал ант беріп.

Жол атаң «енем баласы»
Жатырқауды білмейді,
Ортайса да шарасы,
Арамдыққа жүрмейді.

Кісіні көрсең, ессікке
Жүгіре шық, кешікпе.
Қарсы алмасаң мейманды,
Кесір болар несіпке!
```

## Мәтіндік ескертпелер

- «екекуін» — «екеуін» болуы ықтимал (басылым қатесі).
- «ессікке» — «есікке».
- «қылықпе» — «қылықпен» немесе «қылықпа?» нұсқасы болуы мүмкін.

## Дереккөздік мәні

Тарихи оқиға дерегі жоқ; **әлеуметтік норма дерегі** бар: қонақ күту (`қарсы алмасаң
мейманды, кесір болар несіпке`), адалдық, ант беру рәсімі. «Жауқашардың тоғызын»
деген жол «Бәкеге» жырында да қайталанады — екі мәтін бір оқиғаға қатысты болуы мүмкін
(қараңыз: `03-bakege.md`).
