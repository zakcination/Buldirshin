# Ей, Ақтанберді, Қабанбай!

| Өріс | Мәлімет |
|---|---|
| Автор | Үмбетей жырау Тілеуұлы |
| Жанр | Сын-арнау |
| Кімге арналған | Ақтамберді жырау (мәтінде «Ақтанберді»), Қаракерей Қабанбай батыр |
| Шамамен айтылған жылы | 1750–1768 аралығы (екеуі де тірі, хан ордасы жұмыс істеп тұрған кез) |
| Мәтін көзі | Тапсырмамен ұсынылған нұсқа |
| Тексеру күйі | Академиялық басылыммен салғастырылмаған |

## Мәтін

```
Ей, Ақтанберді, Қабанбай!
Суытпа босқа түсіңді,
Қайрама онша тісіңді.
Сырт тазасы не керек,
Тазарт әуел ішіңді.
Салмақтасаң, айта ғой,
Хан алдында күшінді.
Елімді иесіз демейсің,
Алты арысқа білдірмей,
Басып жеймін демейсің?!
Батпан, батпан мінің бар,
Қабынбай, бітім қылындар.
```

## Дереккөздік мәні — ең маңызды мәтіндердің бірі

Бұл 12 жол қазақ тарихнамасындағы бір қалыпты бұзады: **батырды жырау бетіне басып сынайды**.

1. **Дау жер-қоныс туралы.** «Елімді иесіз демейсің, / Алты арысқа білдірмей, /
   Басып жеймін демейсің?!» — біреудің қонысын иесіз санап, елдің келісімінсіз
   иемдену айыпталады. Бұл жоңғар жеңілгеннен кейінгі (1756 ж. кейін) **бос қалған
   жерді бөлісу** тартысымен үндеседі.
2. **«Хан алдында күшінді» айт** — дау хан сотында шешілуі керек деген қағида;
   батырдың жеке күшіне емес, хандық билік институтына жүгіну.
3. **«Қабынбай, бітім қылындар»** — жыраудың рөлі: араағайын, бітімші.
4. **Ақтамберді мен Қабанбайдың бір мәтінде қатар аталуы** — олардың бір іске
   (немесе бір дауға) қатысы болғанын көрсетеді. Екеуі де Орта жүздің шығыс
   қанатына (Найман) қатысты тұлғалар.

## Ашық сұрақтар

- **«Алты арыс»** нақты қай тайпалық одақ? Мәтінде түсіндірілмейді. Тексеру керек.
- **«Ақтанберді»** — Ақтамберді Сарыұлының есім нұсқасы ма, әлде басқа тұлға ма?
  Қолда бар нұсқада «Ақтанберді» түрінде тұр (тақырыпта да, мәтінде де).
