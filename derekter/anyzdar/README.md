# Аңыздар — ІІ деңгейлі бастапқы дереккөздер

Бұл бумада **батырлық аңыздар мен ауызша дәстүр мәтіндері** сақталады. Олар
`ADISTEME.md` бойынша **ІІ деңгей**: жоғары құнды, бірақ заманхат жыр емес —
ұрпақтан-ұрпаққа өтіп, өзгеріске ұшыраған.

| Файл | Кім туралы | Ұсынылған дереккөзі |
|---|---|---|
| `er-zhanibek-anyzy.md` | Ер Жәнібек Бердәулетұлы (Керей) | **көрсетілмеген** |

## Аңызды жырдан ажырату — неге маңызды

| | Заманхат жыр (I) | Аңыз (II) |
|---|---|---|
| Айтушы | оқиғаның куәгері | кейінгі ұрпақ |
| Тексерілуі | адресат тірі, теріске шығара алады | ешкім тексермейді |
| Уақыт қашықтығы | жылдар | ондаған-жүздеген жыл |
| Фольклорлық қабат | аз | мол (айдаһар, аруақ, аян, дию) |
| Мүдде | ханға/батырға айтылады | **өз руының мәртебесін көтереді** |

Соңғы жол — ең маңыздысы. Аңыз кімнің аузынан шықса, соның мүддесін көтереді.
Сондықтан аңыз **өз руы туралы дау бойынша дербес дәлел бола алмайды** — ол сол
даудың бір тарапы.

## Талап

Жаңа аңыз қосылғанда міндетті түрде көрсетіледі: жинаушысы, жазып алынған жері мен
жылы, айтушысы, жарияланған басылымы. Осы деректер жоқ болса — «көрсетілмеген» деп
ашық жазылады, ойдан толтырылмайды.
