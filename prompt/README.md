# Промпт — үш тілде / Промпт на трёх языках / Prompt in three languages

Осы репозиторийде жасалған зерттеу әдістемесі қайта пайдаланылатын промптқа
айналдырылды. Үш файлдың мазмұны бірдей, тек тілі бөлек.

### Толық нұсқа — агентке / чатқа

| Файл | Тіл | Кімге |
|---|---|---|
| `PROMPT-kk.md` | Қазақша | Қазақ тілді зерттеу, қазақша дереккөздер |
| `PROMPT-ru.md` | Орысша | Орыс тілді архив және академиялық әдебиет |
| `PROMPT-en.md` | Ағылшынша | Халықаралық жарияланым, шетелдік зерттеушілер |

### Қысқа нұсқа — NotebookLM Deep Research өрісіне

Толық промпт NotebookLM-нің зерттеу өрісіне сыймайды (қазақшасы 5 581 таңба, орысшасы 5 898, ағылшыншасы 5 926). `short/`
бумасында екі деңгейлі қысқартылған нұсқа бар:

| Файл | Толық қысқа | Ықшам |
|---|---|---|
| `short/NLM-kk.md` | ≈1 460 таңба | ≈510 таңба |
| `short/NLM-ru.md` | ≈1 630 таңба | ≈595 таңба |
| `short/NLM-en.md` | ≈1 630 таңба | ≈585 таңба |

**Қысқартқанда не алынып тасталды:** дереккөз иерархиясының түсіндірмелі кестесі,
мәтінді оқу ережелерінің егжей-тегжейі (гипербола, тұрақты эпитет, корпусты
қабаттарға бөлу), текстология мен mermaid сызбасы туралы бөлім, сапа өлшемінің
бақылау тізімі.

**Не қалды (өзегі):** дереккөз салмағының реті, A–E деңгейлері, тексерілетін
тұжырым түрлері, үш міндетті тексеру (анахронизм, ішкі хронология, екі куәгер),
бес тыйым, нәтиже құрылымы.

## Қалай пайдалану

1. Керек тілдегі файлды тұтас көшір.
2. `{{...}}` айнымалыларын толтыр:
   - `{{ТҰЛҒА немесе ТАҚЫРЫП}}` — мысалы, «Қаракерей Қабанбай батыр»
   - `{{ЖЫР МӘТІНДЕРІ}}` — бастапқы мәтіндерді сол жерге қой немесе сілтемесін бер
   - `{{Тереңдігі}}` — жеңіл шолу / толық зерттеу / архивке дейін
3. Веб-іздеу қосулы тіл моделіне бер.

## Промпт немен ерекше

Бұл — «маған X туралы айтып бер» деген промпт емес. Ол модельге **дәлел салмағын
өлшеуді** міндеттейді:

- бес деңгейлі дереккөз иерархиясы (Уикипедия — дәлел емес, тексеру нысаны);
- A–E дәлел деңгейлері, белгісіз тұжырым қалдыруға тыйым;
- анахронизм, ішкі хронология, екі куәгер, есім бұрмалануы бойынша міндетті тексерулер;
- қайшылықты жасыруға және олқылықты болжаммен толтыруға тыйым;
- тұлғаны идеалдандыруға тыйым — бастапқы дереккөздегі сын да жазылады.
