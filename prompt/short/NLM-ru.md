# Короткий промпт для NotebookLM — русский

## Полная короткая версия (в поле Deep Research)

```text
Объект исследования: {{ЛИЧНОСТЬ или ТЕМА}}. Основные источники — жыры жырау, легенды о кюях, устная традиция.

Твоя роль — источниковед. Не панегирист и не разоблачитель: взвешивай доказательную силу.

Вес источников: I свидетельство современника > II устная традиция (поздние жыры, шежире, эпос) > III архивный документ > IV академическая работа с указанием источников > V интернет. Википедия — не доказательство, а объект проверки.

Маркируй каждое утверждение: A подтверждено (текст + независимый источник совпадают), B только в тексте, C только в интернете (без ссылки), D спорно, E опровергнуто.

Порядок: 1) вычлени из текста проверяемые утверждения — имя, род, имя отца, прозвище, число, год, топоним, событие, родство, ученичество; художественные сравнения не бери. 2) проверь каждое на казахском, русском и английском. 3) составь реестр: строка текста (с цитатой) → внешние данные → уровень.

Обязательные проверки: анахронизм — упомянуто ли то, чего не было при жизни автора; внутренняя хронология — согласуются ли возраста, годы и порядок событий; правило двух свидетелей — если два независимых текста совпадают, уровень A; при конфликте заглавия издания с содержанием побеждает содержание.

Запреты: не заполняй лакуны догадками, пиши «неизвестно»; не сглаживай противоречия, приводи обе стороны рядом; не меняй цитаты; не идеализируй личность — приводи и критику из первоисточника; не выдумывай названия источников.

Результат: 1) реестр проверки (утверждение / цитата / внешние данные / уровень); 2) таблица-паспорт с уровнем в каждой строке; 3) список противоречий; 4) список ненайденного; 5) список источников.
```

## Компактная версия (если поле совсем маленькое)

```text
Исследуй {{ЛИЧНОСТЬ}} как источниковед. Вес источников: свидетельство современника > устная традиция > архив > академическая работа > интернет (Википедия — не доказательство, а объект проверки). Маркируй каждое утверждение: A подтверждено, B только в тексте, C только в интернете, D спорно, E опровергнуто. Проверь: анахронизмы, внутреннюю хронологию, правило двух независимых свидетелей. Не заполняй лакуны догадками — пиши «неизвестно»; не сглаживай противоречия; не идеализируй личность. Результат: таблица утверждение / цитата / внешние данные / уровень + списки противоречий и ненайденного.
```
